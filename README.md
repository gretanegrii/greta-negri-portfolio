# Portfolio — Greta Negri

My personal website, built from scratch to introduce myself as a
front-end developer with a background in graphic design.

> A designer's eye, learning to build. This site is where the two meet.

## About

I'm Greta Negri, a graphic designer (NABA Milan) transitioning into
front-end development. I designed and coded this portfolio myself —
from the type system to the last line of CSS — as both a business card
and a playground to practice building what I design.

## Design

The whole site follows a Swiss / brutalist visual identity:

- **Typography:** Switzer, self-hosted, on a strict typographic scale
- **Palette:** black · paper white · grey, with rice-pink (#FF4FA3) as
  the single accent
- **Layout:** grid-driven, generous whitespace, no decoration for its
  own sake

## Pages

- `index.html` — home
- `chi-sono.html` — about me
- `lavori.html` — selected work

## Built with

- HTML5, hand-written
- CSS3 (custom, no framework)
- Self-hosted Switzer typeface

No build tools, no libraries — everything is written by hand on purpose,
to actually learn the fundamentals.

## Status

🚧 Work in progress — actively building while I study front-end development.
